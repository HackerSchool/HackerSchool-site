# Novo Site da HackerSchool feito com React

Este ano um dos objetivos da HackerSchool é actualizar o site e migrar para uma framework de React.

---
## Instalação 

Clonar o repositório:

```
git clone git@github.com:HackerSchool/HackerSchool-site.git
```


Instalar as dependências:
```bash
cd HackerSchool-site
npm i
```

## Desenvolvimento:

Para iniciar um servidor local em modo desenvolvimento basta usar:

```bash
npm run dev
```

O site estará disponível em `http://localhost:5173`.

## Build Final

Para fazer uma build de produção basta correr:

```bash
npm run build
```
